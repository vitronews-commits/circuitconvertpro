# Σχέδιο υλοποίησης

## Αλλαγές στο UI
- Αφαίρεση του πεδίου “Optional notes” και μεταφορά του τίτλου του schematic ακριβώς πάνω από την εικόνα.
- Προσθήκη οπτικής προεπισκόπησης για KiCad και EAGLE πριν από τα αντίστοιχα κουμπιά Download, με κοινή απεικόνιση των πραγματικών placements, pins, labels και routed wires.
- Αναβάθμιση του Component editor σε λευκό grid τύπου EasyEDA, με καφέ σύμβολα, πράσινα wires, επιλογή/drag σε snap grid και άμεση ενημέρωση των συνδέσεων.

## Exporters και έλεγχοι
- Διόρθωση της EAGLE βιβλιοθήκης ώστε κάθε deviceset να έχει έγκυρο gate/symbol και πλήρες pin-to-pad connect mapping, αποφεύγοντας “Missing gate reference”.
- Ενίσχυση των validators ώστε να ελέγχουν gates, devices, connects και pin references πριν ενεργοποιηθεί το Download.
- Διατήρηση ανεξάρτητου verification ανά μορφή και εμφάνιση της αντίστοιχης προεπισκόπησης μόνο από το παραγόμενο, επιβεβαιωμένο layout.

## Automated regression tests
- Προσθήκη αντιπροσωπευτικών fixtures (RC κύκλωμα, transistor stage, multi-pin IC) και tests για KiCad/EAGLE generation και validation.
- Κάλυψη malformed/missing gate περιπτώσεων ώστε το συγκεκριμένο EAGLE regression να μην επανεμφανιστεί.
- Εκτέλεση των tests και οπτικός έλεγχος της εφαρμογής σε desktop και στο τρέχον mobile μέγεθος.

## Τεχνικές λεπτομέρειες
- Η προεπισκόπηση και ο editor θα χρησιμοποιούν το κοινό format-neutral layout, ώστε αυτό που βλέπεις να αντιστοιχεί στις συντεταγμένες των exported αρχείων.
- Τα test scripts θα τρέχουν με το υπάρχον Bun test runner, χωρίς νέο runtime dependency.
